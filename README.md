# HA-MGP – Home Assistant MotoGP

Inofficiell integration för MotoGP, Moto2 och Moto3.

**HACS beta-kandidat: `2026.11.0b30` · UI `0.3.0-dev.64`.**

## Nytt i b30
- Banpopuperna placeras något längre ned i fönstret, med bättre säkerhetsmarginal på små skärmar.
- Banillustrationen i popupen från kommande GP får större utrymme (upp till 400 px), i nivå med kalenderpopupen.
- B29:s banfakta, 2026/2027-källmärkning och statusindikatorer bevaras.

Se [release notes](docs/hacs-beta-release-notes.md) och [installationsanvisningar](docs/hacs-beta-installation.md).

**Arbetsflöde:** dev → kandidat → beta → main. B29 kan återställas. Main släpps inte förrän b30 har testats under nästa racehelg och fått uttryckligt klartecken.
