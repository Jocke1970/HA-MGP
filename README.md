# HA-MGP — HACS beta

**HACS beta `2026.11.0b20` · UI `0.3.0-dev.43`.**

b20 är en samlad uppdatering ovanpå b19. Den innehåller den beständiga Pulselive-händelseloggen i `/config/motogp_data/api_diagnostics/YYYY-MM-DD.jsonl` och UI-rättningar för dubbelt Helgschema, sessionens snabbaste varv och toppchippets aktuella session.

Moto3, Moto2 och MotoGP:s befintliga klickbara typografiska klassfilter bibehålls. Grafiken är fortfarande interimistisk text-SVG, inte officiella logotyper.

Installera endast via HACS beta. Registrera en enda JS-resurs `/motogp_sensor/ha-mgp.js`. Ingen separat installation av b19 krävs. Main orörd; rollback b19.
